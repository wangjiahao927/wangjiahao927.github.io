## Что такое Git?

Git — это **распределённая система контроля версий**, созданная Линусом Торвальдсом.

### Основные возможности Git

1. **Распределённая архитектура**: у каждого разработчика полная копия репозитория
2. **Ветвление**: быстрое создание и переключение веток
3. **Целостность данных**: контроль через SHA-1 хеши

## Основные команды Git

| Команда | Описание |
|---------|----------|
| `git init` | Инициализация репозитория |
| `git add` | Добавление файлов в индекс |
| `git commit` | Сохранение изменений |
| `git push` | Отправка на удалённый репозиторий |
| `git pull` | Получение обновлений |

## Заключение

Освоение Git — необходимый навык для разработчика.
